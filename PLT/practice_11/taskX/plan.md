# План опытов до реализации

Практикум 11, задание 1. План записан до первого запуска 08.11.2026.

| Внесённый отказ | Класс | Первоначальная стратегия | Ожидаемое состояние |
|---|---|---|---|
| Пустой файл | Ошибка данных | Прекратить | 0 записей, поле file |
| Количество -1 | Ошибка данных | Прекратить | 0 записей, поле quantity |
| Файл отсутствует | Отказ окружения | Прекратить | 0 записей, причина сохранена |
| Один таймаут справочника | Отказ окружения | Повторить до 3 раз | Успех на попытке 2 |
| Три таймаута справочника | Отказ окружения | Повторить до 3 раз | Отказ на попытке 3 |
| Справочник не вернул обязательный код | Нарушение внешнего контракта | Прекратить | Сохранения нет |
| Превышен лимит строк | Исчерпание ресурса | Прекратить | Сохранения нет |
| Внутренняя сумма отрицательна | Дефект программы | Ранний отказ | Сохранения нет |
| Сбой после первой из двух записей | Отказ окружения | Повторить всю операцию | Предполагалось: 2 записи без дубликата |
| Уведомление недоступно после сохранения | Отказ окружения | Частичный результат | 2 записи, явный признак неполноты |

План допускает три исхода: STOP, OK и PARTIAL. После опыта необходимо проверить гипотезу о повторе частично сохранённой операции: повтор безопасен только при атомарности или идемпотентности.
