# Предсказания до запуска

Практикум 6, задание 1. Эти предположения записаны до первого запуска `task1.py` и `task1.jl`. Это проверяемые учебные гипотезы, в том числе намеренно спорные. Они не являются результатами запуска или утверждением о том, какие ошибки сделал студент.

| Фрагмент | Предсказание основного результата | Причина предположения |
|---|---|---|
| P1 | Первый и второй вызовы напечатают `['новый']` | При каждом вызове создается новый список по умолчанию |
| P2 | У вызывающей стороны получится `[99]` | Присваивание параметру заменяет объект вызывающей стороны |
| P3 | Исходный список останется `[[1]]`, копия станет `[[1, 2], [3]]` | `copy()` копирует вложенное содержимое |
| P4 | Исходный список останется `[[1], [1]]`, глубокая копия станет `[[1, 9], [1]]` | Каждое вхождение вложенного списка копируется независимо |
| J1 | Поле исходного объекта останется `10`, поле второго станет `20` | Присваивание структуры копирует ее поля |
| J2 | Изменение поля вызовет `ErrorException`, исходное значение останется `10`, новая переменная получит `20` | Поле неизменяемой структуры менять запрещено, имя перепривязать разрешено |
| J3 | Добавление элемента вызовет ошибку, вложенный вектор останется `[1]` | Неизменяемость структуры распространяется на содержимое ее поля |
| J4 | После изменения копий исходные элементы в обоих массивах останутся `1`, элементы копий станут `9` | Копирование массива отделяет и содержащиеся в нем объекты |

Идентификаторы P и J означают Python и Julia. Число после буквы обозначает номер фрагмента. После запуска этот файл не исправляется под фактический результат.
