# Практики ВТиИС

Журнал ЯТП и ИКТ по ветке `Andrey`. Каталог включает 30 практикумов и 195 заданий. Ссылки на имеющиеся материалы взяты из снимка `6837c4b`. Задания с файлами изначально помечены «В работе» и «Почти готово», чтобы их можно было проверить перед отметкой «Готово». Остальные доступны как варианты. Обязательность задаётся в редакторе.

В разделе «Без материалов» отображаются задания без файлов в снимке GitHub и без ссылки, добавленной в журнале. Очередь включает незавершённые задания в плане и обязательные задания. Порядок определяется обязательностью, отметкой «Почти готово», оставшимся временем и приоритетом при равном времени. Начальное время по ИКТ взято из методичек, по ЯТП выставлено ориентировочно. Для заданий с отчётом по умолчанию отведено 15 минут на проверку.

## Локальный запуск

Из этой папки с Node.js 24 выполните `node serve.mjs` и откройте `http://127.0.0.1:4173`. Правки сохраняются в `practice-tracker.sqlite`.

## Сборка для Sites

`node build.mjs` собирает Worker в `dist/server/index.js`. В проекте Sites задайте D1-привязку `DB` и примените миграцию из `drizzle/`. Хостинг передаёт идентификатор вошедшего пользователя. Правки хранятся отдельно для каждого пользователя.
