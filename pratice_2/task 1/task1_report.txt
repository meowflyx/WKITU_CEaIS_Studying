«От исходного кода к выполнению программы»

Задание 1
---------
Реализовать вычисление наибольшего общего делителя для всех чисел
вектора и исследовать представления программы на разных этапах выполнения.

Исходные данные
---------------
numbers = [3, 6, 9]

Алгоритм
--------
Использован алгоритм Евклида. Для каждой пары текущего делителя и очередного
числа выполняется последовательность присваиваний:

    divisor, number = number, divisor % number

Перед вычислением берется модуль каждого числа. Для пустого списка предусмотрено
исключение. В Python это ValueError, в Julia это ArgumentError.

Выполнение Python
-----------------
Команда:

    python pratice_2/task1.py

Результат выполнения функции: 3.
Ошибок выполнения не обнаружено.
Также выполнена команда dis.dis(greatest_common_divisor). Она показала байткод
CPython: проверки условия, загрузку элементов списка, цикл FOR_ITER, цикл while,
операцию остатка от деления BINARY_OP и возврат результата RETURN_VALUE.

Выполнение Julia
----------------
Команда:

    julia --project=. pratice_2/task1.jl

Результат выполнения функции: 3.
Ошибок выполнения не обнаружено.

Для работы макросов инспекции в начало task1.jl добавлен импорт:

    using InteractiveUtils

Результаты инспекции Julia
--------------------------
@code_lowered
    Показывает Julia IR после понижения синтаксиса. Видны проверки пустого массива,
    обращение к первому элементу и циклы алгоритма Евклида.

@code_typed
    Показывает типизированное промежуточное представление. Для вызова с
    Vector{Int64} функция специализируется на этом типе и возвращает Int64.

@code_llvm
    Показывает LLVM IR. В выводе присутствуют проверки границ массива, вызовы
    функций Julia runtime, операции над 64-битными целыми числами и ветвления.

@code_native
    Показывает машинные инструкции целевой архитектуры. В выводе присутствуют
    инструкции загрузки, сравнения, переходов, деления и вызова обработчиков
    исключений.

Сравнение Python и Julia
------------------------
Python сначала компилирует исходный код в байткод виртуальной машины CPython.
Команда dis показывает этот байткод.

Julia компилирует функцию с учетом конкретных типов аргументов. Макросы
InteractiveUtils позволяют последовательно увидеть пониженное представление,
типизированный IR, LLVM IR и машинный код.

Цепочки выполнения
------------------
После еще небольшого ресерча я для себя понял, что короче работает это так:

Python:

    PYTHON-КОД -> КОМПИЛЯЦИЯ В БАЙТКОД -> ИНТЕРПРЕТАЦИЯ БАЙТКОДА CPYTHON
    -> МАШИННЫЙ КОД САМОГО CPYTHON -> ПРОЦЕССОР

Julia:

    JULIA-КОД -> JULIA IR -> ТИПИЗИРОВАННЫЙ IR -> LLVM IR
    -> JIT-КОМПИЛЯЦИЯ В МАШИННЫЙ КОД -> ПРОЦЕССОР

Компиляция это преобразование программы в другое представление. Интерпретация -
выполнение этого представления виртуальной машиной. Поэтому нельзя строго
называть язык только компилируемым или интерпретируемым: разные этапы могут
компилироваться или интерпретироваться. CPython компилирует Python-код в
байткод, а затем интерпретирует его. Julia во время выполнения компилирует
типизированные функции в машинный код через LLVM.
